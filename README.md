# AI Coding Plugins

A focused collection of plugins that helps AI coding agents find what matters, plan with confidence, and understand C# code with compiler-level precision.

Built for Codex, Claude Code, and Cursor, each plugin solves a distinct productivity bottleneck while fitting naturally into the way you already work.

## Plugins

### [Find Files](plugins/find-files)

Find any file or folder on your Windows machine in an instant. Find Files gives your coding agent fast, reliable access to files beyond the current repository—so less time is spent searching and more time is spent building.

### [Plan Forge Flow](plugins/plan-forge-flow)

Turn ambitious ideas into implementation-ready plans. Plan Forge Flow brings structured planning, independent review, controlled execution, and a final quality check into one guided workflow—helping you move from intent to trusted results with confidence.

### [Roslyn MCP](plugins/roslyn-mcp)

Give your coding agent a true understanding of your C# solution. Roslyn MCP connects it to Visual Studio's live code intelligence, making navigation, impact analysis, diagnostics, and refactoring more accurate—even across large and complex codebases.

### [Explain Code Simply](plugins/explain-code-simply)

Understand code, errors, and C#/.NET concepts in plain language. Explain Code Simply breaks down complex code logic, exceptions, and technical patterns into clear explanations that respect your expertise while avoiding unnecessary jargon.

## Choose the Right Plugin

| When you want to... | Choose |
|---|---|
| Find files anywhere on Windows | **Find Files** |
| Plan and deliver complex changes with stronger review | **Plan Forge Flow** |
| Work confidently in C# and .NET solutions | **Roslyn MCP** |
| Understand code and C#/.NET concepts in plain language | **Explain Code Simply** |

Use one plugin for a focused boost, or combine them for a more capable AI-assisted development workflow.
